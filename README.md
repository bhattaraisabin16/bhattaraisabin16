## 📌 Featured projects

### 🔮 Telecom Churn Prediction — AUC 0.857
**[github.com/bhattaraisabin16/Telecom_Churn_Prediction](https://github.com/bhattaraisabin16/Telecom_Churn_Prediction)**
Logistic regression model that flags which telecom customers are about to churn, so a retention team can act before they leave. Full pipeline: EDA → feature engineering → model → business recommendations. Headline findings: customers with no contract renewal and 6+ service calls sit at ~95% churn risk; a data plan cuts churn by ~40%.

### 🏠 California Housing Price Prediction
**[github.com/bhattaraisabin16/Housing-Price-Prediction](https://github.com/bhattaraisabin16/Housing-Price-Prediction)**
Linear Regression vs Random Forest on 20,640 California districts (Random Forest wins: R² 0.807, RMSE $50,253). The interesting result isn't the model — it's that **median income beats location** as the strongest price predictor.

### 📈 Stock DCF Valuation Models — *in progress, repo coming soon*
A 31-company discounted-cash-flow valuation calculator built from SEC filing data, with a library of ten+ valuation models (two-stage DCF, reverse DCF, Buffett owner earnings, Greenwald EPV, residual income and more) and a view of every company "through the legends' eyes" (Buffett, Graham, Lynch, Munger, Marks). I refine the methodology a little every night — it's my long-running project to build the best DCF model I can.
